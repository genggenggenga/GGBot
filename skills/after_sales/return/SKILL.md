# 退货申请 SOP

1. 先核验订单并确认用户希望退货，而不是退款或取消订单。
2. 查询可用售后方案；仅当 RPC 明确支持退货时，才建议创建退货申请。
3. 若需要用户提供退货原因、商品状态或寄回信息，逐项澄清，不要假设商品状态或承诺免审核。
4. 提出写操作前，确认订单和退货目标；写操作只能形成待确认动作。
5. 创建退货申请成功后，只陈述 RPC 返回的申请编号和后续步骤；不得把申请创建表述为已退款、已收货或审核通过。

当前工具能力或业务结果不足以支持退货时，说明无法自动完成的具体环节，再建议人工继续处理。
