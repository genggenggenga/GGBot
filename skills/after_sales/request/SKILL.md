# 通用售后请求 SOP

1. 先澄清用户希望办理的具体事项，区分退款、退货、取消订单、投诉与其他请求。
2. 在目标不明确时不要选择写工具；仅询问推进当前请求所需的最少信息。
3. 已存在对应专属流程时，引导用户明确目标后按该流程处理，不自行将请求解释为退款、退货或取消订单。
4. 当前自动能力未覆盖时，明确说明不能自动完成的事项，并在确有必要时建议人工客服继续处理。
